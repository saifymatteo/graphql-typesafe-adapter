graphql_typesafe_adapter library

Type-safe GraphQL queries and mutations built with Type Fragments.

Classes

GqlProp
Wrapper class for props' key and object if available. Primarily used for dynamic definition of GqlResponseConfig.allResponseConfigs
GqlRequestBuilder
GraphQL documents string builder from type-safe request configurations.
GqlRequestConfig
Shared contract for any request config (query or mutation).

Mixins

GqlCustomInputParser
All custom type have to mix with GqlCustomInputParser in order for the custom parser to work in formatArgInputValue.
GqlErrorResponseConfig
Used only as an identifier in resolveFragments
GqlMutationRequestConfig
Used in GqlRequestBuilder.mutate for recursive generation of Mutations and Fragments.
GqlQueryRequestConfig
Used in GqlRequestBuilder.query for recursive generation of Queries and Fragments.
GqlRequestInputConfig
GqlResponseConfig
Used to mix together with other ResponseConfig for recursive generation of Fragments.
